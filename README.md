## 🎯 درباره یارا

**یارا** یک داشبورد اختصاصی، سریع و هوشمند برای مرورگر شماست که با باز کردن تب جدید، همه‌ی ابزارهای روزمره‌تان را در یک محیط فارسی، امن و Local-First در اختیارتان می‌گذارد.

تمام داده‌ها فقط در مرورگر خودتان ذخیره می‌شود. **هیچ اطلاعاتی به سرور ارسال نمی‌گردد.**

## ✨ امکانات کامل
